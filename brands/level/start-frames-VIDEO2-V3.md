# IRYN — Start Frame Prompts (Nano Banana Pro 2) · Video 2 all variants + Video 3·1 beat

22 start frames. Each one is the first frame of a Kling clip (Part 2 of the doc).

## How to run these
- **Model:** Nano Banana Pro 2 · **Aspect:** 9:16 · **Resolution:** 2K (4K if you have it) · **1 image per generation.**
- **Attach the reference images in the order listed** for each frame. The prompt names them "Image 1", "Image 2" and so on, so the order matters.
- **Run the 3 anchors first:** SF-V21-A, SF-V22-A, SF-V23-A (one per mum). Check that each face matches her reference, then run the rest. If a face drifts, re-roll the anchor before you make more. Every other frame of that mum copies the anchor.
- **Once an anchor is approved, add it as an extra reference** (last in the list) for that mum's remaining frames. It locks her face and wardrobe across the set.
- **Mouths are closed in every frame on purpose:** the Kling clip starts her talking from a neutral mouth, which keeps lip-sync clean.
- **Product is locked from your 5 photos:** matte black square tin, rounded corners, **7.5 cm × 7.5 cm, 2 cm tall**, hinged lid. Black foil sachets sit inside, each holding one thin **brown** square strip. All label artwork is copied from the photos, never invented.

**Reference image names (what each upload is):**
- `REF-MUM-BLUE` = blonde woman, blue shirt, outdoor selfie (V2·1 and V3·1 mum)
- `REF-MUM-KITCHEN` = brunette, "MAMA" tank, kitchen selfie (V2·2 mum)
- `REF-MUM-SPORT` = new gym mum, flexing mirror selfie (V2·3 mum)
- `REF-SELFIE-FRAMING` = curly-blonde selfie (framing only, never her face)
- `REF-POSE-PHONE` = brunette on the floor by the sofa with a phone (pose and mood only, never her face)
- `REF-SOFA` = light ribbed sectional sofa, window blinds
- `REF-LAMP-ROOM` = living room with TV and warm floor lamp
- `REF-KITCHEN` = white kitchen with grey island and pendant lights
- `REF-CAR` = beige car interior
- `REF-TRACK` = high school track and bleachers
- `REF-TIN-HERO` = tin with raspberries and two sachets
- `REF-TIN-FRONT` = tin front, straight on
- `REF-TIN-SACHET` = tin with a sachet leaning on it
- `REF-TIN-OPEN` = open tin with a sachet inside
- `REF-STRIP` = sachet with the brown strip

**Paste these blocks where a prompt says so** (they're also written into every prompt in full, so each prompt is copy-paste ready):
- *Realism:* shot on an iPhone front camera, true-to-life color, real skin with visible pores, fine lines and slight under-eye shadows, a few flyaway hairs, no beauty filter, no retouching, light phone-camera grain, a lived-in real home rather than a staged set.

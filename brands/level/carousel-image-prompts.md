> 9 images: the 8 carousel slides + ingredients. All **square 1:1**.
> **Workflow:** do **STEP 0 first** to make the master product image. Then reuse that image as the reference wherever a prompt says so.
> **Brand colors** (names + hex as a nudge — image models read the names best): deep **garnet** red `#A0203F`, warm **cream** `#F4ECDF`, warm near-black **ink** `#2B1418`, muted antique **gold** `#D8A24A`. Font look: clean geometric technical sans (Space Grotesk style).
> **Reference legend:** 🟥 ATTACH PRODUCT IMAGE (the STEP 0 output) before pasting · 🎨 ATTACH SLIDE 1 as a style reference (keeps the set consistent) · ⬜ no reference needed.
> **Text tip:** ChatGPT renders short text well but can misspell on dense cards. If any text comes out wrong, regenerate 2–3×, or generate the card and we drop the text in cleanly in Canva.

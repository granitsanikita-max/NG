# NG — Dropshipping Brand Operating System

The shared brain for Nikita's parallel dropshipping sessions.

- **How it works:** see [`CLAUDE.md`](./CLAUDE.md) — the operating manual every session follows.
- **Sessions (stations):** [`sessions/`](./sessions/) — one charter per session.
- **Brands:** [`brands/`](./brands/) — one folder per brand; `_BOARD.md` is the dispatch board; `_TEMPLATE/` is the blank to copy.
- **Scratch:** [`scratch/`](./scratch/) — misc notes from the Daily Tasks session.

Each session is a station on an assembly line. A brand moves station to station.
Every station reads the same brand folder, does its one job, writes its own file,
commits, and hands off. State is shared between sessions through git — **pull
before you read, push after you write.**

# Prompt 0b — Brand brief (ONE pass; every later pass reads this instead of the whole brain)

Read `{{RUN_DIR}}/00-intake.md` first: it says which files are the source of truth and which are superseded.
Then read EVERY foundational doc it lists, in full. For files over ~1 MB (e.g. a data-bank CSV) read the header + use Grep for the columns you need; don't Read them whole.
Where files disagree, the one marked CURRENT / newest date wins; list each conflict at the end.

Write `{{RUN_DIR}}/00-brief.md`, max 2,500 words, with exactly these sections:
1. **Product + mechanism**: what it is, how it works, variants/sizes. Note anything UNVERIFIED (e.g. waiting on a sample).
2. **Brand voice + attitude**: tone rules, words they use, the look of the creative.
3. **Segments**: the buyer groups, which one leads, one line each.
4. **APPROVED CLAIMS**: every product/benefit claim the brand allows, VERBATIM, each with `(source: file §section)`.
5. **APPROVED OFFER FACTS**: prices, bundles, guarantee wording (verbatim), swaps, shipping.
6. **APPROVED PROOF**: real review counts, ratings, testimonials, customer numbers. If none: write "NONE: ads show no social-proof numbers."
7. **BANNED**: claims, words, styles, and competitor-naming rules.
8. **Awareness + sophistication read**: where the market sits, with the source.
9. **Customer voice highlights**: 15 strongest verbatim lines from the brain's customer research (with source), for later passes to cross-check.
10. **Existing swipes / creative history**: what's been made or run before (from SCRIPTS/CREATIVES/STATE), marked current or outdated.
11. **Conflicts found** between files.

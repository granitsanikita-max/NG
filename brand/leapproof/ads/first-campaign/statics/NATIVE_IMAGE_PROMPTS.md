# Leapproof · 12 native statics: Nano Banana Pro image prompts

These go with the ready-to-paste natives doc (https://docs.google.com/document/d/1ztpU_gxqrfpfzYBOAXA5oVI33Xjqg8l0F6PcCOpGUjs/edit). There is one prompt per ad, N1–N12, matching that doc's IMAGE line.

**Settings for every image**
- Model: Nano Banana Pro.
- Aspect ratio: **4:5**. Resolution: 2K.
- Generate 3–4 variations and pick the one that looks least like an ad.

**Reference images to attach**
- **PRODUCT ref** (attach on N3, N6, N8, N9, N10, N11 and N12): `https://cdn.shopify.com/s/files/1/1026/8593/3939/files/leapproof-brief.png`. It's the store's own pair photo, so the ads match the store. Swap in your phone photo of the real CJ sample once it lands.

**Why the prompts are written this way.** A native has to look like *her* photo, not an ad. Every prompt asks for an unedited iPhone shot with:
- slightly crooked, off-centre framing;
- phone HDR and a little shadow noise;
- no cinematic blur and no studio light;
- real clutter;
- no text or logos.

All panty liners are clean, unused, unbranded, in pastel wrappers. There are never stains.

**No screens, no screenshots, no UI** (v2, 2026-10-15): N2 and N12 were screen images and didn't read as her photo, so both are now real-life phone snaps. Every product prompt now says to use the reference ONLY for the garment, so the store photo's studio look doesn't leak in.

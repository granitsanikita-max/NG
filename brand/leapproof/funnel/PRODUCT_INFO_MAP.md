# LEAPPROOF — Product Information Map (where every product fact lives, CJ launch)

**Principle:** product info is placed where it kills a doubt, not dumped in a spec block. Every number has ONE source value (ties to `NUMBER_SHEET.md` — the one-number rule) so it never drifts across quiz, PDP, checkout, emails and the Shopify listing. Locked to the CJ claims column (FUNNEL_PLAN §2).

**Form legend:** `chart` = sizing table · `accordion` = tap-to-expand on PDP · `line` = one sentence inline · `table` = spec/comparison grid · `card` = quiz screen.

## 0. The claims rule for product facts (read first)
On the CJ period panty, with no lab report on file:
- **Absorbency:** NO millilitre figure, NO "absorbs X", NO absorbency rating anywhere. Only honest, qualitative "best for" language tied to her Q4 answer. (A real ml claim needs a lab test on this SKU — not done.)
- **Safety (PFAS/materials):** NO "PFAS-free", "non-toxic", "antibacterial", "medical-grade". Only what's verifiable: the fibre composition printed on the garment, "machine washable", and an honest "what's tested / not yet tested" status line.
- **Mechanism:** NO Leak-Lock, NO "built for pee not blood", NO layer-by-layer performance claim. You may describe construction that is *visibly true* of the sample ("a soft top layer, an absorbent middle, a leak-resistant outer") as description, not performance.
- Everything below obeys this. If a fact isn't verifiable, it doesn't go on the page.

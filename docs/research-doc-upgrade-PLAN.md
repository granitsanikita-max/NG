## PART 3 — ADD / DELETE / STRENGTHEN (the full list)

### ➕ ADD
1. **4-doc output** (Part 2) + Top-5 takeaways per doc + Drive folder.
2. **§0B Demand & Market Size** — tools: Winning Hunter `search_exploding_topics` (search volume/growth), `search_tiktok_products` (sales), `search_facebook_ads` (advertiser counts), Firecrawl for Google Trends/Amazon. Output: a demand verdict with numbers, not a vibe.
3. **Price ladder** — the same product's price on AliExpress / Amazon / TikTok Shop / top DTC stores. Sets your price ceiling and how much brand you have to build to justify it.
4. **§3A Segments** — pick ONE primary avatar with a reason, list the rest as future test lanes.
5. **Frequency counting** — every pain, desire, objection, failed solution gets a count ("31 of 120 mentions"). Lists ranked top-down. This tells you what to lead with.
6. **Minimum research sample** — target 100+ real customer mentions across 4+ source types (Reddit, Amazon 1–2★ AND 4–5★, TikTok/YouTube comments, forums/Trustpilot). Floor 50. Actual numbers always reported.
7. **Evidence tags on every claim** — `[S#]` source number + type: VERBATIM (page opened + confirmed) · SNIPPET (search-result text, confirm before using in an ad) · DATA (tool estimate, e.g. WH revenue) · INFERENCE (my reasoning, no source).
8. **Hook & Angle Bank** (25+) + **Angle lanes** — direct fuel for Step 3/4.
9. **Go / No-Go Scorecard** — painkiller? proven demand? uncontested? margin? compliance risk? product can back the claim? → GO / GO WITH CONDITIONS / KILL.
10. **"Words she never uses"** in Voice — kills clinical/marketer language before it reaches copy.
11. **Riskiest assumptions → test first** — the 3 things most likely wrong, and the cheapest ad test that proves each.
12. **Science check on the mechanism** — CONFIRMED / PLAUSIBLE / UNSUPPORTED per claim, with source.
